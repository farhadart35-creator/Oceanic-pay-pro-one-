# Oceanic Pay Pro One 🌊
A Django-based secure wallet and transfer system with GitHub OAuth login.

**By Farhad Albert Nikzad**

### Features
- 🔐 GitHub OAuth Login
- 💳 Wallet Balance & Top-up
- 💸 P2P Transfer
- 📊 Transaction History
- 📱 PWA Ready

### Tech Stack
Django 5.0, Python, SQLite, GitHub OAuth

### Run
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
